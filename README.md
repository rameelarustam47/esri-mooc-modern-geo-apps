# Esri MOOC: Make an Impact with Modern Geo Apps (2026)
## 🛠️ Independent Capstone Application: Punjab, Pakistan Flood Suite

This repository documents my independent technical applications completed during the official 4-week Esri Academy Massive Open Online Course (MOOC). 

While the standard curriculum provides pre-packaged tutorial data, I chose to apply every software milestone to a self-directed case study: **Mapping and analyzing the monsoon flood dynamics across Punjab, Pakistan** using live satellite data.

#### 📡 Week 1 Technical Implementation Notes:
1. **Satellite Stream Configuration:** Integrated the live, global **Sentinel-2 Multispectral Imagery** layer natively into the map document.
2. **Spatial Extents & Bookmarks:** Established three geographic bookmarks to track unique hydrological hazards across Punjab:
   * **Kasur (Sutlej River Basin):** Set up to observe riverine flooding caused by massive upstream water releases breaching agricultural riverbanks.
   * **Rajanpur (Indus Plain Basin):** Positioned over low-lying terrain acting as a massive drainage basin for slow-moving, prolonged standing water accumulation.
   * **Dera Ghazi Khan (Suleiman Mountain Fringe):** Centered on the alluvial fans where extreme monsoon cloudbursts convert mountain channels into high-velocity flash hill torrents.
